# Momentum

A self-hosted PHP social-networking and content-community platform, with a full admin dashboard, used within the Limelight project.

## What it does

- Admin dashboard for managing the platform, its users, and its content
- Article and content publishing with categories and custom pages
- User profiles with configurable profile fields, plus moderation tools (ban users, reports)
- Multi-language support across 20+ bundled language packs
- Monetization: ads, affiliates, paid memberships, and bank/receipt handling
- Events, sitemaps, cron jobs, backups, and email/notification settings

## Stack

- PHP (server-side), MySQL-backed
- jQuery / Bootstrap admin UI with chart and datatable widgets
- OneSignal for push notifications
- PayPal and 2Checkout payment integrations

## Structure

- `admin-panel/` — the management dashboard and its page modules
- `assets/` — core includes, language packs, and payment libraries

> Built on a licensed third-party PHP community/social-network script and adapted for the Limelight project.
